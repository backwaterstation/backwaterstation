## CSC-317 Intro to Web Software Development

  This course was intended to get us familiar with web design using HTML/CSS and JavaScript, as well as working with Express.js to intrdouce us to web application frameworks. The first two assignments were quite 
  elementary, and were created to get us comfortable working with these languages. The third assignment allowed us to get much more creative with these languages, which is where I created a simple point and click game 
  using an HTML canvas.


## CSC-413 Software Development

  Now that we have some experience with data structures and object-oriented programming, this course showed us standard industry methods used for data design and problem solution. This also included debugging and testing,
  as well as utilization of other software development tools such as Postman and MongoDB. Weekly assignments were worked on during class, and a midterm homework assignment was also completed.


## CSC-415 Operating Systems

  Working with C and Linux, this course took us through the fundamentals of an operating system, from file and executable management, to storage and memory solutions. Several topics were covered, such as basic
  synchronization techniques, deadlock, multithreading, and general security. There were a multitude of homework assignments during the semester, and a group project that tasked us with designing and coding a file system
  compatible with basic Linux commands.
  

## CSC-648 Software Engineering

  This course was focused entirely on the senior Capstone project. Working with a group, we were to create a fully-functioning web application from scratch, which consisted of creating a tech stack, architecture,
  documentation, and the application itself. I served as a frontend developer and the github organizer, as I was responsible for testing an approving branch merges from the other team members. I also created a map
  search feature for our application.


## CSC-671 Deep Learning

  We focused on the history and progression of technologies that eventually drove us to where our current knowledge base is today in regards to deep learning models, beginning with the perceptron and coming all the way
  to the transformer model that is currently in use by many large language models. We worked in groups of four on the final term project, which was the creation and application of a deep learning model on our own.
  

## CSC-675 Intro to Databases

  Serving as an introduction to database creation and management, this course worked entirely in MySQL using DataGrip. We worked in teams to create a multimedia database system that functioned similarly to an application
  like Netflix. I served as team lead for this project, and worked on each part with the members of my team, including the documentation, ERD, EER, and queries for the database.
